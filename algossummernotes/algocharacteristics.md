# Characteristics of Algorithm

What are the main characteristics of an algorithm?
* **Input**
    * An algorithm can take zero or more inputs.
* **Output**
    * An algorithm _must generate **at least 1 output**_, otherwise it defeats the purpose of writing an algorithm.
    * A function in Java, for example, may not return a value – It may be a void function, but it's executing some type of action.
* **Definiteness**
    * Every statement in an algorithm must have a single and exact meaning.
    * You shouldn't write any statements that can't be understood or solved. (_If we can't solve it, we can't ask computers to solve it._)
* **Finiteness**
    * An algorithm **must terminate** at some point. A function has a limited set of steps and it'll stop and return a result.
    * The duration of algorithm must be finite.
* **Effectiveness**
    * Avoid writing unnecessary statements in an algorithm. Whatever statements you write, it should serve some purpose in the procedure / steps of an algorithm.
 
A great example of this is a recipe. A recipe requires some inputs, which in this case would be ingredients. The output would be the dish you create from following a recipe. To create the dish, you are performing known steps, nothing magical. The instructions for a recipe will end at some point, when you've created the dish. As per effectiveness, you wouldn't cut up vegetables that you're not going to use for the recipe.
