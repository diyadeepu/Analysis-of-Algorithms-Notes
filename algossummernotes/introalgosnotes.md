# Introduction to Algorithms Notes
##### * Content from Abdul Bari's Youtube Series on Algorithms *

### What is an algorithm?
A step by step procedure for solving a computational problem.

In the phases of developing a software project, there are two important phases: **_design_** and **_implementation_**.
* Whatever you're trying to manufacture / construct by engineering procedures, make your design perfect and thorough to get a clear picture of what you want to build or develop.
* You can't build anything simply from trial and error. First **_design_**, then write the **_program_**.

### What's the difference between an algorithm and a program?
While both are step by step procedures to solve a computational problem, algorithms are written at the **_design phase_**, while programs are written at the **_implementation phase_**.
* Those writing an **algorithm** should have domain knowledge.
  * e.g. If you're developing an application for a hospital, then doctors or administrative staff of a hospital can understand the system better than a programmer.
* Programmers will be the ones to write the **program**.
  * They may have domain knowledge.
* **Algorithms** can be written in any language (e.g. English, mathematical notation, etc.), _as long as it's understandable by those people who are using it_.
* **Programs** can only be written in a programming language (e.g. C, C++, Java, Python, etc.)
* **Algorithms** are hardware and software _independent_, but **programs** are hardware and software _dependent_.

### Summarized differences between algorithms and programs

| Algorithms | Programs |
| --- | --- |
| Created at the design phase | Created at the implementation phase |
| Person with domain knowledge should write algorithms | Programmers should write programs |
| Can be written in any language | Written only in a programming language |
| Doesn't rely on Hardware & Software | Relies heavily on Hardware & Software |
| Used for analysis | Used for testing |
